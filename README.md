# Student Management System (JavaScript)

A simple Student Management System built using **JavaScript only**. This project helps manage student records through basic CRUD operations.

## Features

- Add a student
- View student records
- Update student information
- Delete a student
- Manage student data using JavaScript

## Technologies Used

- JavaScript

## Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Run the JavaScript file in the environment used by your project.

> This project uses JavaScript only. It does not use HTML or CSS.

This project was created for practice and learning JavaScript fundamentals, including working with student data and implementing CRUD operations.
